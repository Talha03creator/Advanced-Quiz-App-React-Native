# Advanced Quiz App (React Native + JSON)

A high-performance, minimalist Quiz Application built with React Native and Expo. It features a modern dark aesthetic with gold accents and an efficient JSON-driven question engine.

## 🚀 Tech Stack
- **Framework:** Expo SDK 54 / React Native
- **Navigation:** React Navigation (Native Stack)
- **Algorithm:** Fisher-Yates Shuffle for randomized question ordering
- **Data:** Dynamic JSON Loading

## ✨ Features
- **15-Second Timer:** Urgency-driven countdown for each question.
- **Premium Design:** Dark Gold & Black minimal aesthetic.
- **Dynamic JSON Engine:** Questions and categories loaded directly from local JSON files.
- **Performance Review:** Detailed post-quiz analysis highlighting correct and incorrect answers.

## 🛠️ Setup Instructions

Follow these steps to run the project locally:

1. **Install Dependencies:**
   ```bash
   npm install
   ```

2. **Start the Development Server:**
   ```bash
   npx expo start
   ```

3. **Run on Device:**
   Scan the generated QR code using the Expo Go app on your mobile device.
